# 🌙 Insomnia

Web app per combattere l'insonnia: tecniche (CBT-I, rilassamento, respiro guidato), gestione dei pensieri persistenti, suoni rilassanti generati offline con timer di spegnimento, tisane e ricette, alimentazione, stile di vita, esercizi serali con guida a tempo e diario del sonno.

Installabile come app (PWA): apri il sito da Chrome su Android → menu ⋮ → "Aggiungi a schermata Home".

*Informazioni generali, non sostituiscono il parere medico.*
